# Our Love — Simple Landing / Demo

A small HTML/CSS project containing a landing page demo. This repository holds static assets and markup for a personal or celebratory web page.

## Key features
- Single-page HTML layout
- Responsive CSS styling
- Static assets (images, icons) included

## Tech stack
- HTML5, CSS3, JavaScript (optional)

## Setup
1. Clone the repository.
2. Open `index.html` in your browser or serve the folder with a static server (e.g., `python -m http.server`).

## Notes
This README was added so the repository is presentable for job applications and profile sharing. Feel free to personalize content and images.
